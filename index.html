Nullscape Upgrade Calculator

How to use

  1. Set your lobby's player cap and difficulty.
  2. Every shop, set your current level, the current number of players, and how many golden gifts you have. If you have the "Nothing?" curse, select that as well.
  3. If you are starting in the middle of a game, select your currently obtained upgrades.
  4. In the Current Shop, select the upgrades you want to buy.
  5. When you are ready to buy, hit "Buy selected".

Prices are based on the incomplete Nullscape wiki, so there may be some inaccuracies. If you find any errors, please message @placom on discord.
