Nullscape Upgrade Calculator

How to use

  1. Set your lobby's player cap and difficulty.
  2. Every shop, set your current level, the current number of players, and how many golden gifts you have.
  3. Select the upgrades you would like.
  4. After purchasing, you can hit "Set obtained upgrades". These upgrades will no longer count towards the cost.

Prices are based on the incomplete Nullscape wiki, so there may be some inaccuracies.
